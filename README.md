# Нарядчик — Telegram-бот для нарядов

## Запуск (Windows)
1. Установите Python 3.11+ (python.org), поставьте галочку **Add Python to PATH**.
2. В Telegram: @BotFather → `/newbot` → получите **токен**.
3. Распакуйте архив, дважды щёлкните **start.bat**.
4. Откройте созданный `.env` Блокнотом, после `BOT_TOKEN=` вставьте токен, сохраните.
5. Снова **start.bat**. Когда написано «Бот запущен» — работает. Окно не закрывайте.

## Обновление со старой версии
Скопируйте из старой папки в новую файлы `.env` и `naryadchik.sqlite3` (и папку `backups`), потом запустите start.bat.
Старые наряды сохранятся, статус «Требует продолжения» станет «Отложен».

## Первые шаги
1. Нажмите /start у бота (вы администратор — ваш ID в `ADMIN_IDS`).
2. Пусть мастера тоже нажмут /start.
3. «🏠 Меню» → «👥 Пользователи» → имя → роль (мастеру ещё подразделение).

## Рабочая группа
1. Добавьте бота в группу мастеров.
2. Напишите в группе `/chatid` — бот пришлёт число.
3. Впишите его в `.env` после `GROUP_CHAT_ID=`, перезапустите бота.
Наряд в группу сам НЕ уходит: откройте наряд и нажмите «📣 В чат мастерам».
Дальнейшие изменения (перенос, отмена, завершение и т. д.) в группу идут только по нарядам, которые уже были отправлены.

## Кто что видит
- Мастер: создаёт наряды своего отдела, «Мои наряды», наряды и архив отдела, настройки.
- Ответственный: все наряды с действиями + «👁 Просмотр всех» (компактный список только для чтения), статистика, список пользователей.
- Администратор: всё это + роли пользователей, удалённые наряды (можно восстановить), копия базы, запуск напоминаний.

## Статусы
🟢 Активный · ⏸ Отложен (срока нет, причина обязательна) · 🔵 Завершён (можно добавить примечание, потом «📣 Отчитаться в чат») · 🔴 Отменён (причина обязательна) · 🗄 В архиве.
«📅 Перенести» — новая дата и смена, прежняя дата остаётся в истории.

## Напоминания, копии, отчёты
- Каждый день в `REMINDER_TIME` (по умолчанию 08:00): работы на сегодня — мастерам лично и сводкой в группу (только наряды, отправленные в чат). Один наряд — одно напоминание.
- Если бот был выключен в это время, проверка выполнится при запуске.


## Сводки и вечерний отчёт
- В «🏠 Меню» над кнопками — сводка дня: просрочено, на сегодня, отложено, выполнено.
- В карточках активных нарядов значок срочности: 🔴 просрочен · 🟡 срок сегодня · 🟢 по плану.
- Каждое утро в 07:00 (`MORNING_HM` в начале bot.py) администраторам и ответственным приходит сводка: просроченные, на сегодня, отложенные. Выключается в «⚙️ Настройки» → «Выключить напоминания». Админ может отправить её сразу кнопкой «☀️ Утренняя сводка сейчас».
- «🌙 Отчёт за смену» (администратор и ответственный): за сегодня или вчера — выполнено, не выполнено, отложено, перенесено, отменено. Имя мастера — ссылка на личный чат, чтобы спросить причину.

## Резервные копии
Каждый день в `BACKUP_TIME` (03:00) бот делает копию базы в папку `backups` и хранит последние 20 (`BACKUP_KEEP`).
Если копию сделать не удалось, администратор получит сообщение. В «⚙️ Настройки» админ может создать копию сразу или скачать её.
Чтобы копия лежала не только на компьютере, поставьте в `.env` `BACKUP_SEND_TO_ADMIN=1` — бот будет присылать файл администратору в Telegram.
Восстановление: остановить бота, взять файл из `backups`, переименовать в `naryadchik.sqlite3` и положить на место старого.

## Отчёты в Excel
«🏠 Меню» → «📊 Статистика»:
- «📥 Excel» — выгрузка по текущим фильтрам;
- «📑 Отчёт по подразделению» — выбрать подразделение и период (сегодня, 7/30 дней, этот/прошлый месяц, всё время, свой период);
- «📑 Отчёт по мастеру» — выбрать мастера и период.
В файле пять листов: «Сводка» (итоги, % завершённых, просрочено, переносы и правки, разбивки), «Наряды» (все поля карточки + кто и когда создал, отправил в чат, завершил, отложил, отменил, перенёс; примечания и причины; все правки с «было → стало»), «По дням», «История» (каждое событие по каждому наряду) и «Удалённые» (наряды, удалённые из архива, с датой и тем, кто удалил).
